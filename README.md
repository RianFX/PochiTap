# PochiTap

A simple and cute tapping game for Android!

PochiTap is a casual tapping game where players tap the screen to earn points and beat their highest score.

## Features

- Simple and fun tapping gameplay
- Score system
- High score tracking
- Sound effects
- Easy-to-use interface

## Built With

- Kotlin
- Jetpack Compose
- Android SDK

## Download

Download the latest APK from the [Releases](../../releases) page.

## Installation

1. Download the APK from Releases.
2. Open the downloaded APK on your Android device.
3. Follow the installation instructions.
